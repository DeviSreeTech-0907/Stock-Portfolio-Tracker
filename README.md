# Stock Portfolio Tracker

## Task 2

A simple Python-based Stock Portfolio Tracker that calculates the total investment value using manually defined stock prices.

## Features

* Accepts stock symbol from the user
* Accepts quantity of shares
* Uses a hardcoded dictionary for stock prices
* Calculates total investment value
* Saves the portfolio result to a text file

## Technologies Used

* Python
* Dictionary
* User Input/Output
* Arithmetic Operations
* File Handling

## Stock Prices

| Stock | Price |
| ----- | ----: |
| AAPL  |  $180 |
| TSLA  |  $250 |
| GOOGL |  $150 |
| MSFT  |  $420 |
| AMZN  |  $180 |

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python stock_portfolio.py
```

5. Enter the stock symbol.
6. Enter the quantity.

## Example

For 5 shares of AAPL:

**Total Investment = $180 × 5 = $900**

The result is also saved in `portfolio.txt`.
